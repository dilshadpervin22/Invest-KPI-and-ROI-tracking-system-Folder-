# Invest-KPI-and-ROI-tracking-system-Folder-
Investment KPI & ROI Tracking System

A financial analytics project designed to track investment performance, portfolio risk, return, diversification, and scenario-based outcomes.

Key Features

- Stock Price Analysis – Organized historical stock price data for portfolio evaluation.
- Stock Weight Analysis – Calculates and tracks the weight of each stock in the portfolio.
- Initial Investment Tracking – Records the capital invested across different stocks.
- Return Calculation – Calculates individual and overall portfolio returns.
- Cumulative Returns – Tracks the growth of portfolio returns over time.
- Risk Analysis – Visualizes portfolio risk through comparative bar charts.
- Performance Metrics – Evaluates portfolio performance using key financial metrics.
- Correlation Matrix – Identifies relationships between different stocks.
- Stock Pair Correlation – Examines the correlation between individual stock pairs.
- Diversification KPI Cards – Provides a quick view of portfolio diversification indicators.
- Scenario Analysis – Evaluates how different market scenarios can affect portfolio performance.

Objective

The main objective of this project is to create a structured investment tracking system that combines ROI analysis, risk assessment, performance measurement, correlation analysis, diversification, and scenario analysis in one dashboard.
